# Big Cabal Developer Assessment

## Overview

This repository contains my solutions to the Big Cabal developer assessment. It includes code implementations, written responses, security considerations, troubleshooting approaches, and technical explanations for the assigned tasks.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/MOTY12/bcm-developer-test.git
cd bcm-developer-test
```

### 2. Review the solutions

Each question or task is organized into its own directory, containing the relevant implementation, explanation, or supporting documentation.

Review the `README.md` file inside each task directory for specific instructions and details.

### 3. Run the checks

Follow the instructions provided in each task directory to run the relevant checks.

Depending on the implementation, these may include:

- Syntax and code validation
- Security checks, including input validation, authorization, and nonce verification where applicable
- Manual testing of expected and edge-case behaviour
- Review of error handling and potential failure scenarios

## Use of AI and Documentation

AI tools and official documentation were used as supporting resources during the assessment.

AI assistance was used to clarify technical concepts, review implementation approaches, identify potential security concerns, and improve the clarity of written explanations.

I reviewed the suggestions against the assessment requirements, checked the relevant code and technical details, and made the final decisions on the submitted solutions. AI-generated suggestions were treated as guidance rather than automatically accepted as correct.

Official documentation was consulted where necessary to verify relevant technical behaviour and implementation details.
